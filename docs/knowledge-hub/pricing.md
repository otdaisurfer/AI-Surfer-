# Pricing and Implementation Offers 🌊

Ocean Tide Drop AI SURFER uses a simple three-level implementation ladder.

The goal is not to push every business into the biggest package.

The goal is to match the business to the **smallest useful implementation that can create a meaningful result**.

<Tip>
  Not sure which offer fits? Start with the **Free AI Wave Check** and let the strongest opportunity guide the recommendation.
</Tip>

## Compare the Offers

| Offer | Price | Best fit | Buying path |
| --- | ---: | --- | --- |
| **Wave Starter** | **$497** | One focused AI implementation sprint | Buy directly |
| **Wave Builder** | **$1,997** | Connected lead flow, follow-up, visibility, or automation systems | Strategy call |
| **Tsunami Growth** | **$3,997** | Multi-area AI strategy and deeper implementation | Strategy call |

## Wave Starter — $497

**Best for:** businesses with one clear problem that can be improved with a focused AI implementation.

Wave Starter is designed to turn one identified opportunity into a practical working system.

Examples may include:

- lead follow-up automation
- a focused customer support workflow
- a lightweight content system
- one operational automation
- a targeted AI visibility improvement
- a simple lead-capture improvement

### What the customer should leave with

- one clearly defined implementation goal
- a focused build
- a working first version
- basic handoff or usage guidance
- a measurable result to watch

<Card title="Wave Starter" icon="water">
  **$497** — the direct-purchase path for one focused AI win.
</Card>

## Wave Builder — $1,997

**Best for:** businesses that need more than one connected piece working together.

Wave Builder can be a fit when the opportunity involves combinations such as:

- lead capture + follow-up
- visibility + conversion
- customer intake + automation
- content + lead nurture
- multiple connected workflows
- a deeper AEO/GEO implementation

### What the customer should leave with

- a broader implementation plan
- connected systems or workflows
- stronger handoffs between tools
- clearer operating guidance
- a measurable growth or efficiency outcome

Because Wave Builder is more customized, the preferred buying path is a **strategy call** before implementation begins.

## Tsunami Growth — $3,997

**Best for:** businesses with a multi-area opportunity that needs coordinated strategy and implementation.

Tsunami Growth is designed for situations where several business systems need to work together.

Examples may include:

- AI-search visibility
- lead capture
- sales follow-up
- content production
- customer support
- workflow automation
- multiple specialist AI agents

### What the customer should leave with

- a coordinated AI strategy
- a multi-system implementation plan
- multiple connected workflows or agents
- clearer priorities across the customer journey
- a transformation roadmap with measurable checkpoints

The preferred buying path is a **strategy call** before the build begins.

## Which Offer Fits?

<Steps>
  <Step title="Start with the business problem">
    Identify the strongest opportunity before choosing a package.
  </Step>

  <Step title="Choose the smallest useful build">
    If one focused implementation can solve the problem, start with Wave Starter.
  </Step>

  <Step title="Move up only when the opportunity is broader">
    Use Wave Builder when multiple connected systems are needed, and Tsunami Growth when the business needs a coordinated multi-area transformation.
  </Step>
</Steps>
