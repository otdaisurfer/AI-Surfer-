# Members Dashboard 🐬📊

The **Members Dashboard** is the customer command center for Ocean Tide Drop AI SURFER.

It brings together the tools, specialist agents, saved outputs, implementation resources, and next-step guidance a member needs without forcing them to hunt across different systems.

The goal is simple:

**Open the dashboard, know what matters, take the next useful action.**

<Tip>
  The dashboard should feel less like a software control panel and more like a business cockpit: clear signals, useful tools, and an obvious next move.
</Tip>

## What the Dashboard Helps Members Do

A strong dashboard should help a member answer three questions quickly:

1. **What should I work on next?**
2. **Which AI tool or agent fits that task?**
3. **What result did I get last time?**

Everything on the page should support one of those decisions.

## Specialist Agent Access

Depending on membership level, product configuration, or implementation package, members can work with specialist agents including:

- **Wave Scout** — opportunity discovery and lead intelligence
- **Sales Rider** — lead capture and follow-up
- **Content Creator** — campaign and content production
- **Customer Care Cove** — customer support and response workflows
- **Automation Architect** — process and workflow automation
- **Big Kahuna** — strategy and multi-system coordination

## Member Tools

The Members Dashboard can also include lightweight tools that create standalone value between larger projects.

Examples include:

- prompt builder
- offer builder
- follow-up message generator
- content idea generator
- 30-day campaign planner
- customer FAQ builder
- automation opportunity finder
- lead-leak checker
- time-leak checker
- AEO question mapper
- AI visibility checklist
- business workflow helper

These tools give members a reason to return regularly instead of only logging in when a project is underway.

## Saved Work

Members should be able to return to important outputs such as:

- AI Wave Reports
- AEO Wave Audits
- AI Opportunity Reports
- AEO Blueprints
- Automation Blueprints
- 30-Day Wave Plans
- generated campaigns
- follow-up messages
- saved prompts
- implementation notes
- recommended next actions

The dashboard should preserve context so members do not have to start from zero each time.

## Progress View

A simple progress area can show where the member is in the AI SURFER journey:

**Discover → Diagnose → Plan → Implement → Transform**

Examples:

- Wave Check completed
- Audit recommended
- Blueprint ready
- Implementation in progress
- Agent deployed
- Result measured
- Next opportunity identified

This keeps the larger transformation visible without making the experience feel complicated.

## Recommended Dashboard Layout

A practical member home screen can prioritize:

<Steps>
  <Step title="Show the next best action">
    Put the most useful recommended move at the top instead of forcing the member to decide where to begin.
  </Step>

  <Step title="Surface active work">
    Show any current implementation, audit, campaign, or unfinished task.
  </Step>

  <Step title="Provide quick tools">
    Keep the most frequently used business helpers one tap away.
  </Step>

  <Step title="Show recent outputs">
    Let members reopen their latest reports, plans, and generated work without searching.
  </Step>

  <Step title="Offer the right agent">
    Recommend a specialist agent when the member's next task clearly matches one.
  </Step>
</Steps>

## Business Outcome Focus

The dashboard should avoid overwhelming members with technical metrics unless those numbers help make a decision.

Useful outcome-focused signals may include:

- leads captured
- follow-ups completed
- time saved
- workflows automated
- content produced
- support requests handled
- visibility tasks completed
- implementation progress
- opportunities identified

The question behind every metric should be:

**What does this help the business owner do next?**
