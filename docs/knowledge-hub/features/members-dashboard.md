# Members Dashboard

The Members Dashboard is the customer command center for AI SURFER tools, agent access, saved outputs, and implementation resources.

## What Members Can Access

Depending on access level and product configuration, members can work with specialist tools and AI agents including:

- Wave Scout;
- Sales Rider;
- Content Creator;
- Customer Care Cove;
- Automation Architect;
- Big Kahuna.

## Dashboard Goal

The dashboard should help a member answer three questions quickly:

1. **What should I work on next?**
2. **Which AI tool or agent fits that task?**
3. **What result did I get last time?**

The experience should favor clear actions and business outcomes over technical jargon.
