# Launch Desk 🚀🌊

**Launch Desk** is the operating workspace for moving AI SURFER projects from idea to live business system.

It is built around one simple rule:

**A project is not finished when the code works. It is finished when the full customer path works.**

That means the experience, data flow, payments, handoffs, automation, and follow-up all need to work together.

<Tip>
  Launch Desk keeps implementation focused on the sequence **Secure → Stabilize → Deploy → Revenue** so important launch work does not get skipped.
</Tip>

## 1. Secure

The **Secure** phase protects the foundation before traffic and customer data begin flowing through the system.

Typical checks include:

- authentication and account access
- API keys and secrets
- database permissions
- payment handoffs
- lead and customer data paths
- sensitive configuration
- public vs. private routes
- third-party integrations
- retention and privacy requirements

The goal is to prevent launch speed from creating avoidable risk.

## 2. Stabilize

The **Stabilize** phase makes the experience reliable enough to trust.

This includes:

- fixing broken routes
- removing misleading success or error states
- testing forms and saves
- checking mobile behavior
- verifying important buttons and links
- testing AI-generated outputs
- checking retries and failure paths
- confirming that data reaches the correct destination
- running repeatable evaluations

A feature should work more than once before it earns the word **stable**.

## 3. Deploy

The **Deploy** phase moves verified work into production.

Typical work includes:

- production builds
- environment configuration
- domain and DNS checks
- production secrets
- live API connections
- database migrations
- deployment verification
- production smoke tests
- rollback readiness

<Note>
  A successful deployment only proves that something shipped. Launch Desk also checks whether the live customer experience still works after deployment.
</Note>

## 4. Revenue

The **Revenue** phase connects the technical system to an actual business outcome.

For AI SURFER, that can mean confirming the complete path:

**Visit → Lead → Assessment → Recommendation → Offer → Payment or Strategy Call → Follow-Up**

Launch Desk checks whether the system can:

- capture a qualified lead
- save the lead correctly
- generate the expected report or recommendation
- present the right offer
- route a **Wave Starter** buyer into payment
- route **Wave Builder** or **Tsunami Growth** prospects into a strategy call
- record the handoff
- trigger follow-up
- preserve enough context for the next conversation

## Launch Standard

AI SURFER does not treat a project as launch-ready based on one successful test.

A strong launch standard checks:

- the **customer path**
- the **offer path**
- the **data path**
- the **payment or booking path**
- the **failure path**
- the **follow-up path**

These should be tested together because a funnel can look perfect while quietly dropping data somewhere underneath.

## Evaluation Gates

Before a major launch, Launch Desk can use evaluation gates such as:

- at least **30 of 36** defined evaluations completed
- at least **80% weighted pass rate**
- **no critical violations**
- live offer verified end to end

These gates create a repeatable launch standard instead of relying on memory or a last-minute visual check.

## What Launch Desk Tracks

Launch Desk can organize work across:

- tasks
- blockers
- decisions
- launch phases
- test results
- deployment status
- offer verification
- integration readiness
- follow-up readiness
- remaining launch risk

## Why It Matters

AI projects often fail in the last ten percent.

The chatbot works, but the lead never saves.  
The form works, but the payment link is wrong.  
The deployment succeeds, but production secrets are missing.  
The customer buys, but nobody follows up.

Launch Desk exists to close those gaps.
