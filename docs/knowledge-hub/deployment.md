# Deployment

AI SURFER is built for a modern web deployment stack with React, Vite, TypeScript, Cloudflare, Supabase, Stripe, and OpenAI-powered workflows.

## Frontend

The public experience is delivered through React and Vite, with Cloudflare Pages used for production hosting.

## Server and Edge Functions

Cloudflare Workers / Functions support server-side and edge workflows such as secure API requests, lead handling, automation, and health checks.

## Data and Authentication

Supabase provides database and authentication capabilities used by the application.

## Payments

Stripe supports secure checkout and payment handoff for paid offers.

## AI Workflows

OpenAI-powered workflows can support AI Fin, specialist agents, report generation, and implementation experiences.

## Deployment Principle

AI SURFER uses the sequence:

**Secure → Stabilize → Deploy → Revenue**

A deployment is only successful when the live customer journey, data path, and offer path work together.
